# HIGH JUMP ARENA

動画のように、ジャンプの最高到達点を目標ラインと比べるブラウザゲームです。カメラ計測と、カメラなしで試せるデモを搭載しています。

## 遊び方

1. 身長と**立位リーチ**（床に立って腕を伸ばした指先の高さ）を入力します。
2. カメラ計測を選び、頭から足まで映る位置にカメラを置きます。カメラは動かさないでください。
3. 「チャレンジ開始」を押し、約3秒静止して基準位置を測ります。
4. 20秒間ジャンプして、最高到達点を更新します。

カメラを使えないときは「デモ」を選び、開始後に画面のボタンまたはスペースキーでジャンプできます。デモの数値はサンプルです。

## 計測について

MediaPipe Pose Landmarker で頭と両足首を検出します。静止時の足首位置とジャンプ時の足首位置の差から跳躍高を概算し、入力した立位リーチを足して到達点を出します。1台のカメラによる**推定値**であり、正式な身体測定には使えません。カメラを固定し、全身を映すと安定します。

映像はブラウザ内で解析します。姿勢モデルと実行用 WASM は初回に Google と jsDelivr から読み込みます。カメラの利用には HTTPS または localhost が必要です。

## 開発

```bash
npm install
npm run dev
```

`npm run build` で型チェックと本番ビルドを実行します。ビルド結果は `dist/` です。

`main` ブランチへの push で GitHub Actions がビルドを確認します。Web 公開はまだ設定していません。
