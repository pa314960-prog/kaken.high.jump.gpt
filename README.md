# ジャンプ！最高到達点チャレンジ

壁への投影を想定した、ジャンプして手が届いた最高地点を競うブラウザゲームです。MediaPipeによるカメラ計測と、カメラなしで確認できるデモを搭載しています。

## 遊び方

1. 設定から身長と**立位リーチ**（床から、立って腕を伸ばした指先まで）を入力します。
2. カメラを壁と平行に固定し、頭・上げた手・足まで映る位置に立ちます。
3. 「スタート」を押し、片手を上げて約3秒静止します。
4. カウントダウン後、15秒間ジャンプして最高到達点を更新します。

カメラを使えないときは「デモ」を選び、開始後に画面のボタンまたはスペースキーでジャンプできます。デモの数値はサンプルです。

## 計測について

MediaPipe Pose Landmarkerで頭・手・足を検出します。静止時の床位置と立位リーチを基準に、ジャンプ中の指先の高さをcmへ換算します。1台のカメラによる**推定値**であり、正式な身体測定には使えません。カメラを固定し、身体と壁を同じ平面に近づけると安定します。

映像はブラウザ内で解析します。姿勢モデルと実行用 WASM は初回に Google と jsDelivr から読み込みます。カメラの利用には HTTPS または localhost が必要です。

## 開発

```bash
npm install
npm run dev
```

`npm run build` で型チェックと本番ビルドを実行します。ビルド結果は `dist/` です。

`main` ブランチへの push で GitHub Actions がビルドし、GitHub Pages に公開します。
